# History

Dated working notes, kept for the record and not as instructions.

Everything in here was true on the day it was written and was superseded by
something later: a handoff replaced by `PROJECT.md`, a brief for a session
that has since happened, a punchlist whose items shipped, a plan for a slice
that is now code. They stay because the reasoning in them is the part that
does not go stale -- why the camera polls one frame at a time, why the app is
HTML rather than React, what the Fi probe found in each round -- and because a
decision is easier to revisit with its original argument next to it.

Nothing here is linked from the app. The living documents are one level up in
`docs/`; the current state of the project is `PROJECT.md`; every session's
own artefact is in `.dos/outbox/`.
